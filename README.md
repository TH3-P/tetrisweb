# 🎮 Tetris Web (PHP + MySQL + JavaScript)

Un juego de Tetris clásico desarrollado en JavaScript para la interfaz y PHP/MySQL para el sistema de usuarios y la tabla de mejores puntuaciones.

## 🚀 Requisitos previos

Para jugar a este proyecto en tu computadora local necesitas tener instalado:
* **XAMPP**, **WAMP** o **Laragon** (con PHP y MySQL).

---

## 🛠️ Instalación paso a paso

1. **Descargar el repositorio:**
 * Haz clic en el botón verde **Code > Download ZIP** en GitHub y descomprime el contenido.

2. **Mover los archivos a la carpeta web:**
* Si usas **XAMPP**, copia toda la carpeta extraída dentro de:
`C:\xampp\htdocs\tetris\`

3. **Configurar la Base de Datos:**
* Abre XAMPP e inicia los servicios de **Apache** y **MySQL**.
* Entra en tu navegador a `http://localhost/phpmyadmin`.
* Haz clic en la pestaña **Importar** (Import).
* Selecciona el archivo `schema.sql` que viene dentro del proyecto y presiona **Ejecutar**.

4. **¡A jugar!**
* Abre tu navegador e ingresa a:
`http://localhost/tetris/`
